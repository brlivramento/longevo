# Customer Service System – Ticket/Support Management

Customer service system featuring registration, ticket creation, and support ticket tracking.

## Prerequisites

Make sure Docker and Docker Compose are installed and Docker Desktop is running.
    
## Run Locally

1. Clone the project

```bash
  git clone git@github.com:brlivramento/longevo.git
  cd longevosac/projectLongevoSAC
```

2. Build docker

```bash
  docker compose up --build
  docker compose run --rm app composer install --no-interaction
```
