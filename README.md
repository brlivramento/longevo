
# Customer Service System – Ticket/Support Management

A customer service system originally developed in 2017, featuring customer registration, ticket creation, and support ticket tracking.

A legacy project preserved for portfolio and technical reference purposes.

## Prerequisites

Make sure Docker and Docker Compose are installed and the Docker engine is running.

## Run Locally

1. Clone the repository:

```bash
git clone git@github.com:brlivramento/longevo.git
cd longevo/projectLongevoSAC
```

2. Build and start the application:

```bash
docker compose up --build
docker compose run --rm app composer install --no-interaction
```
